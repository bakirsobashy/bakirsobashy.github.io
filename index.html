Kursi

Event booking REST API

A REST API for booking seats at events that never sells more seats than an event has. Its concurrency test sends 50 booking requests at once for a 10-seat event: my first version booked all 50, and the final one sells exactly 10 and turns 40 away, on every run.

  • Race-free booking with one conditional UPDATE, proven by the 50-request test
  • Rotating refresh tokens in HttpOnly cookies, with reuse detection
  • OpenAPI 3.1 docs generated from the Zod validation schemas and checked by every test
  • Tests against a real PostgreSQL, and four required CI checks on every pull request
  • Node.js
  • TypeScript
  • Express 5
  • PostgreSQL
  • Drizzle ORM
  • Docker
  • GitHub Actions
